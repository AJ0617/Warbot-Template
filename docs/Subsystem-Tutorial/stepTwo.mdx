# Step 2: Create Objects and functions

In order to program a robot, we need devices to program
with, such as a motor or a sensor. In this step,
we are going to take a look at how to create objects
and functions to use.

## Declare objects
First, lets's look back to our plan. We want to
intake and outtake. In order to do that, we need
the intake motor and two seperate functions, one
to intake and one to outtake. So to do that,
lets's first declare and define the motor. If you
don't know the different between declare and define,
you can look at this page for an explanation about
the difference.
